VOD 방송 구간 분석

5~10초 간격 저비용 스캔 → 야구 후보 검토 → 역할 지정 → 제한된 정밀 분석. 기본 색상 단서만으로 야구를 확정하지 않습니다.

EXACT는 사용자 확인 구간, APPROXIMATE는 시작/끝+여유 또는 중심±탐색 폭 절반, AUTO는 전체 저비용 스캔입니다. 자동 역할은 unknown이며 수정 후 분석합니다.

빈 JSON 입력은 자동 스캔입니다. unknown 역할·검토 후보는 자세/스카우팅 분석하지 않습니다. 업로드 원본은 수정용으로 서버에 남습니다. 일반 방송 구간은 평가하지 않으며 버퍼는 미리보기용입니다.
